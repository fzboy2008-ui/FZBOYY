FZ BOY PROFILE WEBSITE
======================

Files
-----
- index.html       Main website content
- style.css        Design and responsive layout
- main.js          Typing effect, mobile menu, gallery lightbox, star background
- img/profile.png  Image supplied for the profile/brand artwork

Preview
-------
Open index.html in a browser.

Deploy to Vercel
----------------
1. Create a new project/repository and upload the contents of this folder.
2. Choose the static site / Other framework preset if asked.
3. Leave build command empty and output directory as the project root.
4. Deploy.

Customise
---------
- Update name, descriptions, and project cards in index.html.
- Discord invite is currently https://discord.gg/62xxMq2NKv
- Email is currently fzboy2008@gmail.com
- Replace img/profile.png with your preferred portrait/artwork (keep the same filename).

This is a static website; it does not require a backend or environment variables.
